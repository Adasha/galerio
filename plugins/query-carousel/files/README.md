# Query Carousel Block

A production-ready WordPress plugin that wraps the core **Query Loop** block in a fully accessible, zero-dependency [Embla Carousel](https://www.embla-carousel.com/).

---

## Requirements

| Requirement         | Version  |
|---------------------|----------|
| WordPress           | ≥ 6.4    |
| PHP                 | ≥ 8.1    |
| Node.js (build only)| ≥ 18.x   |

---

## Installation

### From Source

```bash
# 1. Clone into your plugins directory
cd wp-content/plugins
git clone https://github.com/your-org/query-carousel-block.git

# 2. Install Node dependencies and build
cd query-carousel-block
npm install
npm run build

# 3. Activate in WP Admin → Plugins
```

### Pre-built ZIP
Download the release ZIP from the Releases page and install via **WP Admin → Plugins → Add New → Upload Plugin**.

---

## Usage

1. In the block editor, insert the **Query Carousel** block from the *Theme* category (or search "carousel").
2. A default **Query Loop** block is pre-inserted inside it.
3. Configure the Query Loop (post type, filters, template) as you normally would.
4. Use the **Carousel Settings** panel in the sidebar to configure:
   - Transition effect (Slide / Fade, extendable)
   - Autoplay + speed
   - Loop
   - Navigation arrows
   - Pagination dots

## Architecture Decisions

### Option A — Parent Block Container
The block is a **custom block** (`custom/query-carousel`) that accepts `core/query` as its only inner block. This provides clean separation of carousel-configuration markup from the native Query Loop markup, and avoids polluting core block attributes.

### Progressive Enhancement
CSS structural classes (`.query-carousel__viewport`, `.query-carousel__container`, `.query-carousel__slide`) are added by JavaScript at runtime. Without JS, posts render as a normal block list — the carousel never breaks page content.

### Zero Design Opinions
`style.scss` contains **only** layout rules (`overflow: hidden`, `display: flex`, `position: absolute` for fade). No colours, no paddings, no borders. Themes style everything else.

## Extending — PHP Filters

### `query_carousel_transition_effects`

Add custom transition effects to the editor SelectControl.

```php
add_filter( 'query_carousel_transition_effects', function ( array $effects ): array {
    $effects[] = [
        'label' => __( 'Flip', 'my-plugin' ),
        'value' => 'flip',
    ];
    return $effects;
} );
```

The `value` string is written as `data-transition-effect="flip"` on the frontend wrapper. Your theme/plugin JS then handles it (see JS hooks below).

## Extending — JavaScript Hooks

### Register Custom Embla Plugins

```js
// In your theme's JS or a separate plugin:
window.queryCarouselHooks = window.queryCarouselHooks || {};
window.queryCarouselHooks.plugins = window.queryCarouselHooks.plugins || [];

// Example: add the official Embla AutoPlay plugin instead of the built-in one.
import EmblaAutoplay from 'embla-carousel-autoplay';
window.queryCarouselHooks.plugins.push( EmblaAutoplay({ delay: 4000 }) );
```

### Filter Embla Options (WordPress hooks API)

```js
import { addFilter } from '@wordpress/hooks';

addFilter(
    'query_carousel.embla_options',
    'my-theme/drag-free',
    ( options, wrapperElement ) => ({
        ...options,
        dragFree: true,
        containScroll: 'trimSnaps',
    })
);
```

### Filter Transition Effects in Editor (WordPress hooks API)

```js
import { addFilter } from '@wordpress/hooks';

addFilter(
    'query_carousel.transition_effects',
    'my-plugin/flip-effect',
    ( effects ) => [
        ...effects,
        { label: 'Flip', value: 'flip' },
    ]
);
```

### On-Init Callback

```js
window.queryCarouselHooks = window.queryCarouselHooks || {};
window.queryCarouselHooks.onInit = window.queryCarouselHooks.onInit || [];

window.queryCarouselHooks.onInit.push( ( emblaInstance, wrapperElement ) => {
    console.log( 'Carousel initialised on:', wrapperElement );
    // Access any Embla API method:
    console.log( 'Slide count:', emblaInstance.scrollSnapList().length );
} );
```

### Direct DOM Access

After initialisation, each carousel wrapper exposes the Embla instance:

```js
const wrapper = document.querySelector( '.wp-block-custom-query-carousel' );
wrapper.__embla.scrollNext();
```

## Styling

Target the following structural classes in your theme's CSS or `theme.json` `customCss`:

| Class | Element |
|---|---|
| `.wp-block-custom-query-carousel` | Outermost wrapper (add colour, padding, border-radius here) |
| `.query-carousel__viewport` | Scroll-clipping container |
| `.query-carousel__container` | Flex row of slides |
| `.query-carousel__slide` | Individual slide wrapper |
| `.query-carousel__arrow` | Prev/next navigation buttons |
| `.query-carousel__arrow--prev` | Prev button only |
| `.query-carousel__arrow--next` | Next button only |
| `.query-carousel__dots` | Pagination dots container |
| `.query-carousel__dot` | Individual dot button |
| `.query-carousel__dot.is-active` | Active/selected dot |

### CSS Custom Properties for Fade Duration

```css
.wp-block-custom-query-carousel {
    --wp--custom--carousel-fade-duration: 0.6s;
    --wp--custom--carousel-fade-easing: ease-out;
}
```

### theme.json Example (spacing, colours)

```json
{
    "styles": {
        "blocks": {
            "custom/query-carousel": {
                "spacing": {
                    "padding": { "top": "2rem", "bottom": "2rem" }
                },
                "color": {
                    "background": "var(--wp--preset--color--base)"
                }
            }
        }
    }
}
```

## Accessibility

- **ARIA roles**: `role="region"`, `aria-label`, `aria-roledescription="carousel"` on wrapper.
- **Live region**: Slide changes are announced to screen readers via `aria-live="polite"`.
- **Keyboard**: Left/right arrow keys navigate slides when the carousel is focused.
- **Focus management**: Off-screen slides have `tabindex="-1"` applied to all focusable children.
- **Autoplay pauses** on `mouseenter`, `focusin`, and `document.visibilitychange` (tab hidden).
- **Disabled arrows** receive `aria-disabled="true"` at scroll boundaries.
